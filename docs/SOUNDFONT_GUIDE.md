# SoundFont (.sf2) 音源下載與雙槽音源設定教學指南

本指南說明如何為 **Windows MusicXML 真實音源播放器 (WinMusicXmlPlayer)** 下載免費、高品質的開源 `.sf2` (SoundFont 2) 真實樂器取樣音源，並透過內建的**雙槽音源分流系統**配置出最佳的鋼琴與管弦樂協奏音質。

---

## 1. 認識「雙槽音源分流」架構

一般的 General MIDI (GM) 音源為了在單一檔案內塞入 128 種樂器，往往會壓縮鋼琴取樣的容量；而高品質的獨立平台鋼琴 `.sf2` 音源（通常 50 MB ~ 300 MB）則只包含鋼琴一種樂器，若直接拿來播放小提琴協奏曲或交響曲，其他管弦樂聲部會因為找不到對應樂器而無法正常發聲或全部變成鋼琴聲。

為了解決這個問題，本播放器在底層設計了**雙合成器同步混音架構（Dual-Synthesizer Routing）**：

| 音源槽位 | 負責的樂器範圍 | 運作方式 |
| :--- | :--- | :--- |
| **🎹 鋼琴專用音源 (.sf2)** | 鋼琴家族（`GM 001–006`：平台鋼琴、亮音鋼琴、電鋼琴等） | 當有掛載獨立鋼琴 `.sf2` 時，樂譜中所有鋼琴聲部會自動分流至此合成器發聲；若未指定，則自動使用下方通用音源內的鋼琴音色。 |
| **🎻 通用樂器音源 (.sf2)** | 弦樂、木管、銅管、打擊樂等所有其他樂器（`GM 007–128`） | 預設載入隨附的 `TimGM6mb.sf2`，負責除鋼琴外的所有協奏與管弦樂聲部，亦可隨時更換為更大容量的 GM 全樂器音源。 |

### 2.3 下載後的解壓縮注意事項

- 只要下載下來的檔案副檔名已經是 **`.sf2`**，即可直接載入使用，無須解壓縮。
- 若下載的檔案為壓縮包（如 `.zip`、`.7z`、`.tar.gz`、`.tar.bz2`），請先使用 Windows 內建解壓縮或 [7-Zip](https://www.7-zip.org/) 解壓縮，取出裡面的 **`.sf2`** 檔案。

## 3. 音源設定操作步驟教學

### 步驟一：開啟「音源設定」視窗
您可以透過以下任一方式開啟音源設定視窗：
1. 點擊主視窗右上角工具列的 **「🔊 切換音源 (.sf2)」** 按鈕。
2. 點擊頂部系統選單 **「設定(S) → 音源設定 (Ctrl+M)」**。
3. 直接按下鍵盤快捷鍵 **`Ctrl + M`**。

### 步驟二：將下載的 `.sf2` 放入音源資料夾（選用，方便集中管理）
1. 在「音源設定」視窗右上角，點擊 **「📂 開啟音源資料夾」** 按鈕。
2. 系統會自動開啟程式目錄下的 `Assets\SoundFonts` 資料夾。
3. 將您下載並解壓縮好的 `.sf2` 檔案複製到此資料夾中（未來點擊選擇音源時，對話框會預設直接打開這個資料夾）。

### 步驟三：掛載「🎹 鋼琴專用音源」
1. 在「🎹 鋼琴專用音源 (.sf2)」區塊右側，點擊 **「選擇鋼琴 .sf2...」**。
2. 選取您下載的鋼琴專用 `.sf2` 檔案（例如 `SalamanderGrandPiano.sf2` 或 `UprightPianoKW.sf2`）。
3. 程式會在背景高速載入音源（不影響視窗操作），完成後左下角狀態列會顯示：
   `鋼琴：<您的鋼琴音源名稱> ｜ 其他樂器：<目前通用音源名稱>`。
4. 若想取消獨立鋼琴音源，隨時點擊旁邊的 **「停用獨立鋼琴」** 按鈕，鋼琴聲部就會立即回歸使用下方通用音源內的鋼琴音色。

### 步驟四：更換或還原「🎻 通用樂器音源」
1. 在「🎻 通用樂器音源 (.sf2)」區塊右側，點擊 **「選擇通用 .sf2...」**。
2. 選取包含完整 128 種 GM 樂器的 `.sf2` 檔案（例如 `GeneralUser_GS.sf2` 或 `FluidR3_GM.sf2`）。
3. 若想切回程式出廠內建的音源，只需點擊 **「還原預設 TimGM6mb」** 按鈕即可一鍵恢復。

## 4. 進階技巧：拖放 `.sf2` 快速載入與自動記憶

- **拖放快速載入**：您可以直接從 Windows 檔案總管將任何 `.sf2` 檔案**拖曳 (Drag & Drop)** 到播放器主視窗，系統會自動將其載入為通用樂器音源。
- **跨次啟動自動記憶**：您所設定的「鋼琴專用音源路徑」與「通用樂器音源路徑」皆會自動記錄於偏好設定檔中，下次啟動播放器時會自動掛載，無須重複設定。
