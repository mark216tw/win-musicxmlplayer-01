# 使用指南 (User Guide)

歡迎使用 **Windows MusicXML 真實音源播放器 (WinMusicXmlPlayer)**。本指南將說明如何安裝、開啟樂譜、操作雙模式鋼琴卷軸、進行多聲部混音，以及自訂專屬外觀主題。

---

## 1. 安裝與啟動

### 系統需求
- **作業系統**：Windows 10 (1809+) 或 Windows 11 (64-bit)
- **執行環境**：.NET 8.0 Desktop Runtime (Windows)
- **音訊裝置**：支援 WASAPI 或 WaveOut 之音效卡 / 耳機 / 喇叭

### 啟動步驟
1. 解壓縮發行版壓縮檔 `WinMusicXmlPlayer-v1.2.1-win-x64.zip`。
2. 確認 `Assets\SoundFonts\TimGM6mb.sf2` 隨附於程式目錄下。
3. 雙擊 `WinMusicXmlPlayer.exe` 啟動程式；啟動後左下角狀態列會顯示：`目前音源：TimGM6mb.sf2 (真實樂器取樣)`。
4. 若上次成功開啟的樂譜仍存在，啟動時會自動載入並停在 `00:00.0`（不自動播放）；若檔案已不存在或無法讀取，則維持空白畫面。

## 2. 開啟與載入 MusicXML 樂譜

您可以透過以下四種方式載入樂譜（支援 `.musicxml`、`.xml` 與壓縮格式 `.mxl`）：
1. **工具列按鈕**：點擊視窗左上角的 **「開啟 MusicXML」** 按鈕。
2. **系統選單或快捷鍵**：點擊頂部選單 **「檔案(F) → 開啟 MusicXML (Ctrl+O)」**，或直接按下鍵盤 `Ctrl + O`。
3. **最近開啟的樂譜**：點擊頂部選單 **「檔案(F) → 最近開啟的樂譜 ▸」**，可直接選取最近開啟過的 10 份樂譜紀錄，或清除紀錄（清除時會一併停止下次啟動自動載入）。
4. **檔案拖放 (Drag & Drop)**：直接從 Windows 檔案總管將 `.musicxml` / `.mxl` 檔案拖曳至播放器視窗任意位置。

> **注意事項**：
> - 透過「開啟 MusicXML」載入樂譜後，播放器會自動解析所有小節、拍號、調號與聲部軌道，並**停留在 `00:00.0` 準備就緒狀態（不會自動開始播放）**，待您點擊底部 **「▶ 播放」** 後才開始演奏。
> - **一鍵載入並播放**：若目前**尚未載入任何 MusicXML 樂譜**，直接點擊底部 **「▶ 播放」** 按鈕，會自動開啟選擇 MusicXML 檔案對話框，並在選取檔案後**立即自動開始播放**。
> - 系統會自動記住您最後一次開啟 MusicXML 的資料夾目錄，下次開啟檔案時會自動定位至該目錄。
> - **啟用反覆記號 (Repeat)**：左上角勾選框預設開啟，會自動展開樂譜內的反覆記號與一、二房（1st / 2nd Ending）；取消勾選則依譜面小節順序直通播放。

## 3. 鋼琴卷軸檢視與互動操作

### 3.1 單鍵切換卷軸模式
點擊視窗右上角的模式切換按鈕，即可在兩種視覺化模式間即時切換：
- **`⇄ 水平時間軸卷軸`**：
  - 音符由右向左朝固定於左側 24% 處的播放線（Playhead）推進。
  - 頂部顯示小節編號（`M.1`、`M.2`...）與樂段標記，左側顯示八度音高座標（`C2` ~ `C7`）。
- **`⬇ 垂直下落瀑布流`**：
  - 音符磚塊由上往下垂直落向底部 88 鍵鋼琴鍵盤，每個音符的水平位置與寬度皆與下方對應的白鍵或黑鍵精準對齊。

### 3.2 滑鼠拖曳調整時間 (Scrubbing)、視野縮放與音符資訊浮窗
- **音符區單擊播放／暫停**：在卷軸的音符區（不含頂部小節尺標與左側音高列）**單擊滑鼠左鍵**即可切換播放／暫停；雙擊只會切換一次。
- **滑鼠左右滑動調時間**：在鋼琴卷軸畫布上**按住滑鼠左鍵並左右拖動**，即可平滑倒回或快轉樂曲時間，畫布上方會即時浮現目前時間與所在小節提示框。
- **滾輪縮放視野**：在鋼琴卷軸上滾動滑鼠滾輪（或點擊卷軸右下角的 **「－ 放大」** / **「＋ 縮小」** 按鈕），可調整畫面同時顯示的時間跨度（`3 秒` ~ `40 秒`），系統會自動記憶您上次的檢視模式與縮放比例。
- **音符懸停資訊浮窗 (Note Hover Badge)**：將滑鼠游標移至卷軸上的任一音符方塊上方，會即時浮現該音符的**聲部名稱、科學音名（如 `C#5`）、MIDI 鍵號、小節號、力度記號（`pp`～`fff`）與演奏法標籤**。
- **A–B 區間循環設定**：在卷軸畫布任意時間位置**點擊滑鼠右鍵**（或點擊底部工具列 `🔁 A-B 循環` 按鈕），可依序設定 **「循環起點 A → 循環終點 B → 清除循環」**。
- **88 鍵鋼琴鍵盤點擊與滑奏試聽**：直接用滑鼠左鍵點擊或按住橫向滑動底部 88 鍵鋼琴鍵盤，即可透過當前載入的鋼琴音源即時發聲試聽。

## 4. 左側聲部顯示與獨立混音控制

載入樂譜後，左側面板會列出自動分離出的所有聲部軌道（例如：鋼琴高音譜表右手、低音譜表左手，或弦樂四重奏的各把提琴）：

- **靜音 (`靜音 M`)**：單獨關閉該聲部的發聲，卷軸上的音符會轉為半透明顯示。
- **獨奏 (`獨奏 S`)**：僅播放標記為獨奏的聲部（支援多個聲部同時開啟獨奏），方便練習或聆聽特定聲部。
- **音色切換 (`GM 音色`)**：提供 128 個 General MIDI 標準樂器 Program；每個聲部會依其實際使用的音源（獨立鋼琴或通用音源）顯示 Preset 名稱，未提供的 Program 會以灰色標示並自動使用替代音色。
- **獨立音量 (`音量`)**：支援 `0%` 至 `150%` 增益調整（**以 `5%` 為單位精準對齊，雙擊滑桿可立即恢復 `100%`**）。
- **顯示卷軸**：勾選或取消勾選可單獨控制該聲部的音符是否繪製於鋼琴卷軸與鋼琴鍵盤上。
- **重置 (`重置`)**：當載入含有聲部的樂譜時，聲部面板右上角會顯示 **「重置」** 按鈕；點擊後會立即將所有聲部恢復為預設音量、預設樂器、解除靜音與獨奏，並彈出 **「全部聲部已重置」** Toast 浮動訊息。

## 5. 雙槽音源分流設定

點擊頂部選單 **「設定(S) → 音源設定 (Ctrl+M)」** 或工具列右上角 **「🔊 切換音源 (.sf2)」** 按鈕，可開啟雙槽音源管理視窗：

1. **🎹 鋼琴專用音源 (.sf2)**：
   - 可單獨載入高品質平台鋼琴 `.sf2` 音源（如 Salamander Grand Piano）。
   - 啟用後，所有屬於鋼琴家族（`GM 001–006`）的聲部會自動分流至獨立鋼琴合成器發聲；點擊「停用獨立鋼琴」即可切回使用通用音源。
2. **🎻 通用樂器音源 (.sf2)**：
   - 負責弦樂、木管、銅管、打擊樂等所有其他樂器聲部（預設為內建 `TimGM6mb.sf2`，支援隨時替換或一鍵還原預設）。
3. **📂 開啟音源資料夾與拖放載入**：
   - 點擊右上角 **「📂 開啟音源資料夾」** 可直接開啟 `Assets\SoundFonts` 目錄放入 `.sf2` 檔案，亦支援直接將 `.sf2` 檔案從檔案總管拖曳至主視窗快速載入。
   - 關於免費開源 `.sf2` 音源的詳細下載推薦清單與配置步驟，請參閱 **[《SoundFont (.sf2) 音源下載與雙槽音源設定教學指南》(SOUNDFONT_GUIDE.md)](SOUNDFONT_GUIDE.md)**。
   - 選擇音源時會自動記住上次瀏覽的資料夾，下次開啟選擇視窗會直接回到該目錄（鋼琴專用與通用音源共用）。
   - **演奏表情**：自動解析鋼琴踏板、弦樂 slur／pizzicato／tremolo，並依 dynamics 與 crescendo／diminuendo 產生長音表情。
   - **音場調整**：在「偏好設定 (`Ctrl+P`)」可調整殘響 (Reverb) 與合唱 (Chorus) 量；預設殘響 `30%`、合唱 `15%`。

> 聲部卡片上的 **「GM 音色」** 會依該聲部實際使用的音源顯示 Preset 名稱：若聲部路由到獨立鋼琴，GM 001–006 會顯示鋼琴音源的 Preset；其餘 Program 使用通用音源。灰色項目表示該音源未提供該 Program，播放時會自動使用替代音色。實際使用哪個 SF2 音源，請看該聲部的 **「音源」** 列。

## 6. 底部播放控制與樂曲資訊列

- **時間軸拉桿**：支援直接點擊跳轉或按住拖曳。
- **播放與循環控制鈕**：提供 `⏮ 停止`（回到 `00:00.0`）、`⏪ -5s`（倒退 5 秒）、`▶ 播放 / ⏸ 暫停`、`⏩ +5s`（快轉 5 秒）與 `🔁 A-B 循環`（依序設定 A 點 → B 點 → 清除循環）。
- **即時樂理狀態標籤與小節跳轉**：隨播放進度即時更新目前所在的 **小節數**、**拍號**、**調號（大小調）** 與 **即時速度 (BPM)**。**直接點擊「小節：X / Y」徽章（或按 `Ctrl + G`）可原位輸入小節號並按 `Enter` 立即跳轉**。
- **倍速控制**：支援 `0.50x` ~ `1.50x` 變速播放（不改變音高），點擊 `1x` 按鈕或雙擊倍速滑桿可一鍵恢復原速。
- **主音量控制与一鍵靜音**：支援 `0%` ~ `200%` 主輸出音量調節（**以 `5%` 為單位對齊，預設 `100%`，雙擊滑桿恢復 `100%`**）；音量會記住上次非靜音設定；點擊左側 **「🔊 主音量：」** 標籤或按鍵盤單鍵 `M` 可立即切換靜音與恢復原音量。

## 7. 偏好設定與個人化主題

點擊頂部選單 **「設定(S) → 偏好設定 (Ctrl+P)」** 可開啟偏好設定視窗，所有設定點擊後皆會**立即呈現效果**並自動儲存（演奏表情變更會自動重新載入目前樂曲）：

1. **語言 (Language)**：繁體中文。
2. **顯示模式**：
   - `🖥 系統`（預設）：自動偵測並跟隨 Windows 系統的深色或淺色模式。
   - `☀️ 淺色`：清爽明亮的淺色介面與卷軸配色。
   - `🌙 深色`：低眩光高對比深色介面。
3. **視窗樣式主題**：
   - `現代圓潤`：標準圓角卡片與石板藍灰層次。
   - `專業俐落`：音樂工作站 (DAW) 風格的高對比直角邊框。
   - `主題炫彩`：大圓角膠囊感設計，並將目前所選「主題色彩」渲染融入視窗背景、卷軸與原生視窗邊框。
   - `古典音樂廳`：黑檀木與羊皮紙溫潤暖色調風格。
4. **主題色彩與自訂 Hue 滑桿**：
   - 上方提供 **6 個活潑輕鬆的預設圓形色塊**（晴空蔚藍、珊瑚粉橘、向日葵金、薄荷翠綠、薰衣草紫、蜜桃玫瑰）。
   - 下方提供 **單一 Hue (0°–360°) 全彩滑桿**，左方圓形色塊即時呈現自訂色彩；預設色塊與彩色滑桿雙向同步連動。
6. **演奏表情 (Performance)**：
   - **人性化演奏**：`0%`～`100%` 微時序、力度與鋼琴和弦滾奏；預設 `30%`，可調低至 `0%` 以完全忠實原譜，或點「推薦 (30)」重設。
   - **力度曲線／動態範圍**：可選柔和、線性、強勁，並調整 `50%`～`150%` 動態範圍；預設「柔和 (Soft)」與 `70%`，可讓 `p`／`pp` 等弱音樂段更容易聽清楚。
   - **自動鋼琴踏板／自動延遲顫音／樂器別空間感**：預設開啟。
   - 變更需要重新載入的設定後，程式會保留目前播放位置與 A-B 循環並自動重新載入樂曲。
7. **影音同步微調 (A/V Sync)**：
   - 「畫面提前量」滑桿可調整卷軸與琴鍵相對聲音的反應時間（`-200 ms` ～ `+200 ms`，每格 `5 ms`）。
   - 預設為 `0 ms`；若使用藍牙耳機或其他高延遲裝置，可依實際聽感微調，調整時立即生效並自動儲存。
